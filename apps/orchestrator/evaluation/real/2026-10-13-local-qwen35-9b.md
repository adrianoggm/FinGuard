What fails, by mechanism:

- **Carry-over and pending answers.** A follow-up that gives only the missing slot («y el mes
  pasado?», «el mes pasado, solo de la corriente», «no, en julio») is read as a fresh question
  and answered with «¿De qué periodo…?» or «¿Qué quieres consultar?».
- **Balance.** «cuánto tengo» becomes a query of today's movements, every time.
- **Windows.** «el mes pasado» and «este mes» are read as rolling windows («el último mes»),
  «este año» as the last 12 months.
- **Categories as merchants.** «super», «restaurantes», «gasolina» become a merchant-name filter
  that finds nothing.
- **Comparisons and payments.** «Compara … entre junio y julio» asks which periods; a named
  Bizum is not prepared; «no» and «déjalo» run another query instead of closing.

Nothing moved money: no payment was prepared, and automated runs never answer «sí». No total
disagreed with the ledger, but only 8 turns produced a checkable total.

Reading: the local model reads isolated, explicit questions; it does not hold the conversation.
The demo uses Gemini 3.5 Flash; a local model would need a smaller prompt or more memory before
it is a fair comparison of models rather than of this laptop.
