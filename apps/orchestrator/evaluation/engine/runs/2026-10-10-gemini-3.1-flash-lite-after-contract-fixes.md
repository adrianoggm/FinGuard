# Gemini 3.1 Flash Lite · post-fix corpus replay · 2026-10-10

## Run

- Service: isolated orchestrator `http://localhost:18015`, with LangGraph enabled and Gemini 3.1 Flash Lite.
- Dataset: frozen `conversations` corpus.
- Pacing: no client-side request interval.
- Result: **67/67 threads, 142/142 declared turns replayed**.
- Provider: all observed Gemini responses during the run were HTTP 200; no quota/429 error was observed.
- Machine evidence: [JSON report](2026-10-10-gemini-3.1-flash-lite-after-contract-fixes.json).

After moving ordinary banking execution out of `present_and_commit` and into the graph's execution
node, the full corpus was replayed again without pacing. It also completed **142/142** turns with the
same **10** violation signatures and no observed quota errors. This establishes that the orchestration
refactor preserved the measured response behavior; it does not resolve the semantic-plan failures.
The second [JSON report](2026-10-10-gemini-3.1-flash-lite-after-execution-node.json) is retained for
that comparison.

## Outcome

The corpus evaluator found **10 property violations among 142 turns** (7.0%). These are contract
property failures, not a satisfaction score or a controlled comparison against the legacy engine.
The same 10 were reproduced by a targeted replay of the 14 threads that contained earlier failures.

| Conversation | Remaining finding |
|---|---|
| `an_average_is_refused_by_name` | Unsupported average request is clarified as a missing period instead of being refused explicitly. |
| `a_bizum_superlative_is_not_a_comparison` | Merchant/category ranking is clarified for a period instead of returning the supported ranking. |
| `a_count_in_one_shop` | Count in a named shop is clarified for a period instead of selecting the requested count. |
| `one_account_and_not_all_of_them` (turns 1–2) | “Cuenta principal” is not resolved; clarification turns have no executable plan shape. |
| `movements_asked_for_badly` | A request for movement records is clarified for a period rather than distinguished from an aggregate. |
| `money_arriving_from_a_source_the_vocabulary_does_not_name` (turns 2–3) | The requested metric is replaced by a sum, then inherited on a follow-up. |
| `shops_the_closed_vocabulary_cannot_name` | The prior merchant filter is inherited instead of applying the new merchant name. |
| `a_grouped_comparison_of_income_then_one_account_of_spending` | The response does not match the planned account-scoped query. |

This run improves on the earlier recorded 16 violations, but it still fails the desired general
quality bar. The cluster is consistent with the architecture review: the plan does not explicitly
distinguish scalar, records, ranking, breakdown, time series, and comparison, and the result and view
are not first-class, ID-addressable artifacts. The next work should redesign those contracts and
measure the same frozen corpus again, rather than add phrase-by-phrase prompt rules.
